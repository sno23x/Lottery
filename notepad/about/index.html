ดาวน์โหลด KhianPad สำหรับ Mac

ไม่แน่ใจว่า Mac เป็นรุ่นไหน? คลิกเมนู › About This Mac ถ้าเห็นคำว่า “Intel” ให้เลือกรุ่น Intel ถ้าเห็น “Apple M1/M2” ให้เลือกชิป Apple

Intel Mac รุ่น Intel macOS 11 Big Sur+ · .zip M1 / M2 Mac ชิป Apple macOS 11 Big Sur+ · .zip Web ใช้ในเบราว์เซอร์ ไม่ต้องติดตั้ง · Safari / Chrome

ติดตั้งบน macOS 11 ใน 4 ขั้นตอน

  1. 1

    แตกไฟล์ zip

    ดับเบิลคลิกไฟล์ที่ดาวน์โหลดมา จะได้โฟลเดอร์ KhianPad

  2. 2

    คลิกขวาที่ “Install KhianPad.command”

    เลือก Open (เปิด) แล้วกด Open อีกครั้ง โปรแกรมจะถูกคัดลอกไปไว้ใน Applications ให้เอง

  3. 3

    เปิด KhianPad

    หาได้จาก Launchpad หรือโฟลเดอร์ Applications (ครั้งแรกถ้ามีคำเตือน ให้คลิกขวา › Open)

  4. 4

    เริ่มเขียนได้เลย

    ลากไฟล์มาวางบนหน้าต่าง หรือกด ⌘O เพื่อเปิดไฟล์

คำถามที่พบบ่อย

ฟรีจริงไหม?

ฟรีทั้งหมด ไม่มีโฆษณา และไม่ต้องสมัครสมาชิก

macOS บอกว่าแอป “เสียหาย” หรือ “เปิดไม่ได้” ทำอย่างไร?

แอปนี้ไม่ได้ลงทะเบียนกับ Apple ให้ใช้ไฟล์ “Install KhianPad.command” (คลิกขวา › Open) ซึ่งจะแก้ให้เอง หรือเปิด Terminal แล้วพิมพ์: xattr -cr /Applications/KhianPad.app

ไฟล์ของฉันถูกส่งขึ้นอินเทอร์เน็ตไหม?

ไม่ ทุกอย่างทำงานในเครื่องของคุณเท่านั้น

เวอร์ชันเว็บต่างจากแอปอย่างไร?

เวอร์ชันเว็บใช้งานได้เกือบครบ แต่การบันทึกทับไฟล์เดิมและเปิดโฟลเดอร์ทำได้เฉพาะ Chrome/Edge ส่วน Safari จะบันทึกเป็นการดาวน์โหลดไฟล์แทน
